Su integridad se verifica mediante SHA-256.

La información técnica complementaria se encuentra en:

- `manifest_fuentes_metro.csv`
- `inspeccion_fuentes_metro.json`

## Observación metodológica

La procedencia y la integridad representan controles distintos:

- la procedencia identifica quién publica el recurso, de dónde se obtuvo y cuándo;
- el SHA-256 permite comprobar que el archivo utilizado no fue modificado.

Ambos controles deben conservarse para cada nuevo sistema de transporte incorporado al proyecto.
